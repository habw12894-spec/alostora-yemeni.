# تشغيل AVNEX محليًا بدون Render

هذه الحزمة لا تحتاج Render. لتشغيل الخادم وقاعدة البيانات محليًا تحتاج جهازًا يدعم Docker وDocker Compose (عادة كمبيوتر أو خادم خاص).

## المتطلبات
- Docker مع Docker Compose.
- Node.js 20+ فقط إذا أردت تشغيل الخادم خارج Docker.

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. غيّر `POSTGRES_PASSWORD` إلى كلمة مرور محلية قوية.
3. غيّر `JWT_SECRET` إلى قيمة عشوائية طويلة (32 حرفًا على الأقل). لا تشارك ملف `.env`.
4. نفّذ: `docker compose up --build -d`
5. افتح `http://localhost:3000`.
6. افحص `http://localhost:3000/api/health` ويجب أن تظهر قاعدة البيانات متصلة.

## الإيقاف
`docker compose down`

## تنبيه مهم
- هذا تشغيل محلي، وليس نشرًا عامًا على الإنترنت.
- لا يمكن تشغيل Docker/خادم Node.js من متصفح الهاتف وحده عادةً.
- خدمة التسجيل الحالية لا ترسل OTP فعليًا؛ لا تعتبر الحسابات موثقة.
- تخزين الفيديو الحالي محلي داخل volume؛ يلزم تخزين كائنات دائم (مثل S3-compatible) قبل الإنتاج.
- لا تفتح التسجيل للعامة قبل مراجعة الأمان، وتفعيل التحقق، والنسخ الاحتياطي، واختبارات التحميل.
