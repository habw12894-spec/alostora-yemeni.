# AVNEX على الهاتف — نسخة PWA محلية

هذه الحزمة تضبط ملفات موارد التطبيق وأصوله ووصف التثبيت (Web App Manifest):
- `public/assets/icon-192.png` و`icon-512.png` و`icon-maskable-512.png`
- `public/manifest.webmanifest`
- `public/sw.js` للتخزين المؤقت للواجهة للعمل دون اتصال بعد أول زيارة ناجحة
- `public/index.html` مرتبط بالـmanifest وأيقونات الهاتف

## الاستخدام على هاتف Android
1. يلزم تقديم الملفات من عنوان HTTPS حتى يسمح Chrome بتثبيت PWA وتشغيل Service Worker. فتح `index.html` مباشرة من مدير الملفات لا يفعّل التثبيت أو التخزين دون اتصال.
2. ارفع محتويات مجلد `avnex_project/public` إلى استضافة ملفات ثابتة تدعم HTTPS (يمكن استخدام GitHub Pages من المستودع الحالي؛ لا يحتاج Render ولا خادم Node).
3. افتح رابط الموقع في Chrome، ثم القائمة ⋮ ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. افتح الموقع مرة واحدة مع اتصال إنترنت حتى تُخزّن الواجهة والأيقونات مؤقتًا.

## حدود نسخة الهاتف فقط
هذه نسخة PWA للواجهة والتجربة المحلية. إنشاء الحسابات، التفاعلات المحفوظة بين عدة أشخاص، ورفع الفيديوهات إلى جمهور عام تحتاج خادمًا وقاعدة بيانات وتخزينًا سحابيًا. تسجيل الحساب الحالي في الواجهة تجريبي ومحفوظ على الجهاز فقط؛ لا تستخدم كلمة مرور حقيقية أو معلومات حساسة.
