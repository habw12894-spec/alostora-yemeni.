# افنكس — نسخة الواجهة 

## تشغيل سريع
- افتح `index.html` في متصفح حديث.
- هذه نسخة واجهة أمامية تجريبية، وليست منصة إنتاجية متعددة المستخدمين بعد.

## ما يعمل في النموذج
- عرض واجهة عربية متجاوبة.
- كتابة منشورات محلية داخل الصفحة.
- إعجاب تجريبي وتعليقات شكلية.
- مشغل مقاطع تجريبي بملء الشاشة والتنقل بالسحب/عجلة الفأرة.

## ما يلزم قبل النشر العام
1. Backend آمن ومتاح عبر HTTPS.
2. قاعدة بيانات للمستخدمين والمنشورات والتعليقات والمتابعات.
3. مصادقة وتأكيد الهاتف/البريد واستعادة الحساب.
4. تخزين فيديوهات وصور مع معالجة/تحويل الفيديو وبث مناسب.
5. الإبلاغ والحظر والإشراف على المحتوى وسياسة خصوصية وشروط استخدام.
6. حماية من الرسائل المزعجة، تحديد معدلات الطلبات، النسخ الاحتياطي ومراقبة الأعطال.
7. نطاق واستضافة وتهيئة متغيرات البيئة والأسرار خارج ملفات الواجهة.

لا تضع كلمات مرور أو مفاتيح API داخل `index.html`.
