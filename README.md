# افنكس AVNEX

حزمة مشروع أولية قابلة للتشغيل والتطوير لمنصة فيديوهات قصيرة بواجهة عربية RTL وخادم Express وقاعدة PostgreSQL.

## الموجود في الحزمة
- واجهة الويب الحالية في `public/index.html`، مع هوية AVNEX.
- خلفية الهوية البصرية في `public/assets/avnex-splash.png`.
- دعم التثبيت كتطبيق ويب (PWA) عبر `manifest.webmanifest` و`sw.js`.
- خادم Express ومسارات أولية للتسجيل والدخول والملف الشخصي ورفع الفيديو والتعليقات والإعجابات والمتابعة والبلاغات.
- مخطط PostgreSQL في `sql/schema.sql`.

## التشغيل
1. يتطلب Node.js 20 أو أحدث وPostgreSQL.
2. انسخ `.env.example` إلى `.env` واضبط `DATABASE_URL` و`JWT_SECRET` (سر عشوائي طويل لا يقل عن 32 حرفًا).
3. أنشئ قاعدة البيانات ونفّذ `sql/schema.sql` عليها.
4. شغّل `npm install` ثم `npm start`.
5. افتح عنوان الخادم، واختبر `GET /api/health`.

## متغيرات البيئة
راجع `.env.example`. لا ترفع ملف `.env` أو أي أسرار إلى GitHub.

## حدود هذه النسخة — اقرأ قبل الاستخدام العام
هذه نسخة تشغيل/تطوير وليست منصة إنتاجية مكتملة أو منشورة. الواجهة الحالية لم يتم إثبات ربط جميع أزرارها ومساراتها بالـAPI؛ يلزم اختبار وكتابة تكامل الواجهة. تسجيل الهاتف لا يرسل OTP حقيقيًا، والتحقق بالبريد غير مهيأ. تخزين الفيديو محلي على الخادم فقط وغير مناسب للاستضافة المؤقتة أو الإنتاج. لا يوجد بعد نظام إدارة كامل لإنشاء المشرف أو مراجعة المحتوى، ولا محادثات أو إشعارات فورية أو بث مباشر أو تطبيق APK أصلي.

قبل استقبال الجمهور: اربط تخزينًا دائمًا/كائناتيًا للفيديو، مزود SMS موثوقًا، بريدًا إلكترونيًا، أنشئ حساب مشرف بإجراء آمن، فعّل CSP وCORS بدقة، أضف سياسات الخصوصية وشروط الاستخدام وآلية حذف الحساب والبلاغات والإشراف، واختبر النسخ الاحتياطي والأمن والأداء.


##  (ملفات جاهزة)
يوجد ملف `render.yaml` لتعريف خدمة Node وقاعدة PostgreSQL. من Render اختر New → Blueprint ثم اربط مستودع GitHub الذي يحتوي هذا المجلد. راجع الخطة والتكلفة قبل الموافقة على إنشاء الموارد. بعد الإنشاء، افتح قاعدة البيانات ونفّذ محتويات `sql/schema.sql` مرة واحدة باستخدام أداة SQL المتاحة لدى مزود قاعدة البيانات. افحص `/api/health` بعد النشر.

## تنبيه قبل الإطلاق
- لا ترفع `.env` أو كلمات مرور أو مفاتيح إلى GitHub.
- خطة الاستضافة المجانية قد تتوقف أو تنام، وقد لا توفر قرصًا دائمًا؛ لذلك رفع الفيديو الحالي إلى مجلد محلي ليس تخزينًا دائمًا. لا تعتمد عليه لمحتوى المستخدمين قبل ربط تخزين كائنات دائم.
- الواجهة الحالية لا تزال تحتوي على سلوك تجريبي محلي لبعض الحسابات ومعاينة الفيديو؛ لا تعتبر التسجيل أو الرفع في الواجهة متصلًا بالخادم حتى يتم تنفيذ واختبار تكامل الواجهة.
- لا تفتح التسجيل العام قبل تفعيل التحقق الفعلي، إنشاء مشرف بطريقة آمنة، سياسات الإشراف والخصوصية، واختبار الأمان والنسخ الاحتياطي.
